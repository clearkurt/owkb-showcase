# 路线图

> 本文件是公开方向说明，不代表内部生产承诺。

## 近期

- 完善文档元数据与页锚点规范；
- 加强手册表格/图片的转换质量检查；
- 改进检索排序与片段可读性；
- 增加项目案例的复用索引；
- 建立公开/内部内容边界检查。

## 中期

- 更细的 collection 权限模型；
- 多语言检索与同义词；
- 文档变更影响分析；
- 更完整的检索评测集；
- 可选的向量检索混合排序；
- 与更多 agent/IDE 客户端集成。

## 长期

- 跨项目知识图谱（芯片、外设、协议、项目之间的关联）；
- 从源码/手册自动生成可复核的技术卡片；
- 内容生命周期管理（草稿、评审、发布、归档）；
- 可移植的知识库格式，避免绑定单一服务。

## 不追求的方向

- 不做通用文件网盘；
- 不让 agent 直接修改生产知识；
- 不用不可解释的排序替代可追溯的引用；
- 不把内部资料默认公开。
